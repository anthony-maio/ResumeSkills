# Early Career Reference (tech-resume-optimizer)

Material for junior engineers, bootcamp graduates, and career changers — kept out
of the main skill, which targets mid-through-staff engineering. Truthfulness
rules apply identically.

## Projects Section (critical early, fades with experience)

A Projects section matters for junior engineers, career changers, and anyone
with gaps. At senior level, real experience crowds it out — replace with
Publications/Open-source (see main skill).

```
PROJECTS
Distributed Task Queue | Python, Redis, Docker | github.com/user/taskqueue
• Built a distributed task queue handling 10K+ jobs/hour with retries and
  a dead-letter queue
• Implemented priority queuing and rate limiting for multi-tenant support
```

Include: projects with real users, open-source contributions, complex personal
projects, hackathon winners.
Exclude: tutorial follow-alongs, trivial to-do apps, incomplete work, ordinary
coursework.

## Education Formats (early career only)

Recent grads may include graduation year, GPA if 3.5+, and relevant coursework:
```
B.S. Computer Science | Stanford University | 2024
GPA: 3.8/4.0
Relevant Coursework: Distributed Systems, Machine Learning
```

### Bootcamp graduates
```
Software Engineering Certificate | App Academy | 2024
• 1000+ hour immersive program — full-stack JavaScript, React, Node.js
B.A. Economics | UCLA
```
List the bootcamp first if it's the most relevant credential; projects carry the
technical evidence, not the certificate name.

### Self-taught engineers
Lead with demonstrable work (projects, OSS, employment); formal coursework
second:
```
Professional Certifications:
- AWS Solutions Architect Associate | 2024
Self-Directed Study:
- MIT OpenCourseWare: Algorithms, Data Structures
```

## GPA Guidance
- Include only if 3.5+ AND within ~2 years of graduation
- Never after early career — it's noise and an age marker
