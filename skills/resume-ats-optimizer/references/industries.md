# Industry Keyword Reference

Pointer file for resume-ats-optimizer — industry-specific keyword sets for non-tech
domains. The main skill covers tech roles; use these only when the user's target
role is in one of these industries.

## Business/Finance
- Software proficiency: Excel, SAP, Salesforce
- Certifications genuinely required: CPA, CFA, PMP
- Metrics language: P&L, ROI, KPI, EBITDA, ARR/MRR

## Healthcare
- Licenses and certifications are often legally required — list exactly as issued
- Systems: Epic, Cerner, MEDITECH
- Compliance keywords: HIPAA, Joint Commission

## Marketing
- Platforms: HubSpot, Salesforce, Google Analytics
- Channels: SEO, PPC, email marketing
- Metrics: CAC, LTV, conversion rate, attribution

Note: the same truthfulness rules apply — never list a platform, certification,
or methodology the user hasn't confirmed they've used.
