# Industry Keyword Reference

Pointer file for resume-ats-optimizer — industry-specific keyword guidance for
non-tech domains. The main skill covers tech roles; use these only when the
user's target role is in one of these industries. In every industry, the way
to find terms is the same: read the JD, list the nouns it uses for tools,
compliance regimes, and metrics, and mirror the JD's own phrasing for skills
the user truly has.

## Business/Finance
- Software proficiency: Excel, SAP, Salesforce
- Certifications genuinely required: CPA, CFA, PMP
- Metrics language: P&L, ROI, KPI, EBITDA, ARR/MRR
- How to extract: financial JDs name the reporting framework and systems in
  the first bullet — mirror those exactly (e.g., "month-end close", "SOX
  controls") and put the certification acronym in both skills and summary if
  the JD leads with it.

## Healthcare
- Licenses and certifications are often legally required — list exactly as issued
- Systems: Epic, Cerner, MEDITECH
- Compliance keywords: HIPAA, Joint Commission
- How to extract: clinical JDs cite the license body and the EHR system by
  name; both must appear verbatim. Mirror the unit/setting vocabulary
  ("med-surg", "value-based care") from the responsibilities section.

## Marketing
- Platforms: HubSpot, Salesforce, Google Analytics
- Channels: SEO, PPC, email marketing
- Metrics: CAC, LTV, conversion rate, attribution
- How to extract: marketing JDs reveal the metric stack in the "success
  looks like" or KPI lines — mirror those exact metrics (CAC vs. "cost per
  lead") and the martech stack from the tools bullet.

Note: the same truthfulness rules apply — never list a platform, certification,
or methodology the user hasn't confirmed they've used.
